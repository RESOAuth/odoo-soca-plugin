# Security

This is an alpha authentication integration. Keep ordinary SSO disabled until public
metadata checks, an operator-bound real candidate login and local recovery checks
have passed. The requirements evidence records the remaining gaps.

Report vulnerabilities privately through GitHub Security Advisories for this
repository. Do not attach tokens, keys, callback queries or user claims. We aim to
acknowledge reports within five working days. No response or remediation SLA is
promised for the alpha. Critical/high known vulnerabilities block a release.

Dependencies and workflows are pinned, with weekly Dependabot updates. Maintain the
host platform separately. CodeQL scans Python and workflow code. Independent review
and OIDC conformance certification have not been completed.
